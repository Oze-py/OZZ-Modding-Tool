## Installation

1. Install Python
   ```sh
   https://www.python.org/downloads/
   ```
2. Install requirments for script
   ```sh
   pip install tkinter
   ```
3. Install/Clone source code or .exe from releases
   ```sh
   git clone Oze-py/OZZ-Modding-Tool
   ```

4. Run programm by double click
