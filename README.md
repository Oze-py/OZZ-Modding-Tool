## About The Project

OZZ modding tool - simple tool for getting il2cpp encrypted exports and more soon...
### Installation

1. Install Python
   ```sh
   https://www.python.org/downloads/
   ```
2. Install requirments for script
   ```sh
   pip install tkinter
   ```
3. Install source code or .exe from releases
